# JoineryNest 木工榫卯与板材切割清单

基于 React、TypeScript、Vite、Chakra UI、Jotai、React Router 和 Canvas 构建。排料算法与
排料图渲染均为本地实现，项目数据自动保存在浏览器中。

## 功能

- 柜体与桌案零件建模：长、宽、厚、数量、板材和纹理方向
- 榫卯连接设计：燕尾榫、直榫、搭槽、圆木榫和饼干榫
- 余料台账：编号、长宽厚和所属板材一体登记；断网暂存本机，回网按编号合并，
  同一编号只留先登记的一条，重传只入库一次；库位满时排队等位、释放后自动补位
- 余料占用先到先得：两人同时占用同一块余料时，后来者看到占用者并获得可换余料建议
- 排料优先用余料，放不下再开新板；余料不计入新购成本
- 按板材规格生成多张排料图，考虑锯缝、修边余量和纹理限制
- 零件尺寸改动后，受牵连的排料图和成本立即重算，未受牵连的板材沿用原结果
- 利用率、废料面积、板材采购量和预计成本
- 在 Canvas 上拖动或输入坐标微调零件，并标记重叠风险
- 项目文件保存 / 载入（含余料台账），零件表、排料图、用料说明和 SVG 导出
- 旧数据没有余料编号，读取时自动补成首版结构（v1）后照常使用
